# Ghost Wheel

Virtual car race you steer with an invisible steering wheel in front of your laptop webcam.

- **Steering**: MediaPipe Hand Landmarker runs in the browser at camera frame rate. The angle of the line between your two wrists is the wheel angle. Two open palms with fingers spread brake (a grip curls the fingers, so a fist can't be the brake). One hand falls back to left/right hand position.
- **Track**: the real **CMU Buggy Course**. Street geometry for Tech Street, Schenley Drive and Frew Street comes from OpenStreetMap, elevation from Open-Meteo, so Hill 1 and Hill 2 climb, the Free Roll drops ~35 m around Flagstaff Hill, the Chute turns onto Frew, and Hills 3 to 5 grind back up. The real course is point-to-point, so the loop is closed by a return lane up Tech Street beside Hill 1 with a hairpin at the top. Hills change your speed and the HUD names each section as you enter it. A flat fantasy loop is also selectable in the lobby. Seeded cones and barrels are placed on the road. Leave the tarmac and you slow to a crawl; stay off for 2.5 s and you get reset onto the track.
- **Multiplayer**: a tiny WebSocket relay. Everyone in a room sees everyone else's car, the same obstacle layout, and shared race events.
- **Commentator**: every ~7 s the client sends the race state plus a webcam snapshot to the server. Gemini writes a one-liner in the chosen persona (it can see your face), ElevenLabs voices it in the chosen voice. Without API keys, or if a provider errors, it falls back to canned lines and browser text-to-speech, so the demo never goes silent.

## Run it

```bash
npm install
cp .env.example .env   # add GEMINI_API_KEY and ELEVENLABS_API_KEY if you have them
npm run dev            # Vite on :5173, server on :8787
```

Open https://localhost:5173, click through the self-signed certificate warning (Advanced > Proceed), allow the camera, and hold both hands up like you're gripping a wheel.

The dev server uses HTTPS because browsers only allow the webcam on `localhost` or secure origins, and other laptops reach the game by IP address.

**Solo race**: click "Solo race".
**Multiplayer**: one laptop runs `npm run dev`. The server prints a LAN address on startup, and the room panel shows it too. Everyone on the same Wi-Fi opens that address, clicks through the certificate warning, enters the same room code and clicks "Join room". Anyone can press "Start race for everyone"; the host's track choice is used. Up to six players per room.

**Commentator voice and tone**: the 🎙 button (top right, works in the lobby and mid-race) lists the voices in your ElevenLabs account, five tone presets (hype, deadpan golf, trash-talking rival, nature documentary, pirate) and a custom free-text narrator. "Test line" plays a sample. Choices are saved in the browser. Without an ElevenLabs key the list shows the browser's built-in voices instead.

## Layout

```
client/src/hands.ts        webcam + MediaPipe, steering math, overlay drawing
client/src/track.ts        spline road with elevation, terrain, obstacles, nearest-point lookup
client/src/tracks/         track definitions: buggy.json (generated, see below) and fantasy.ts
client/src/car.ts          arcade car physics and mesh
client/src/game.ts         Three.js scene, race loop, laps, collisions, remote cars
client/src/commentator.ts  timing + playback for commentary lines
client/src/net.ts          WebSocket client
client/src/main.ts         lobby wiring
server/index.ts            HTTP + WebSocket relay, static hosting of dist/
server/commentary.ts       Gemini + ElevenLabs calls, canned fallback
```

## Regenerating the Buggy course

`client/src/tracks/buggy.json` was generated by `scripts/build_course.py`: it queries Overpass for the three streets, walks the street graph through the course waypoints, offsets Tech Street into two lanes, adds the hairpin, resamples at 6 m, fetches elevation, smooths it and caps the grade at ~11 %. Re-run it if you want to move the start line, change lane width, or swap in another route:

```bash
python3 scripts/build_course.py    # needs internet; writes client/src/tracks/buggy.json
```

Map data © OpenStreetMap contributors (ODbL). Elevation from Open-Meteo.

## Tuning knobs

- `FULL_LOCK`, `DEADZONE`, `SMOOTHING` in `hands.ts` control steering feel.
- `MAX_SPEED`, `TURN_RATE` in `car.ts` control the car.
- `GRAVITY` and `DOWNHILL_BONUS` in `car.ts` control how much the hills matter.
- `placeObstacles` in `track.ts` sets obstacle density; `sections` in `buggy.json` are the HUD labels.
- `INTERVAL_MS` in `commentator.ts` is how often the announcer speaks.
- `LAPS` in `game.ts`.

## Demo tips

- Bring a lamp. Hand tracking needs your hands well lit against the background.
- Sit about an arm's length from the camera so both hands stay in frame at full lock.
- Test multiplayer on a phone hotspot, not venue Wi-Fi.
